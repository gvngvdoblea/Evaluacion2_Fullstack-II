# El Bajón Urbano - Evaluación 2

Proyecto de comida rápida en React + Vite para la Evaluación 2 de Fullstack II.

### Cómo levantarlo en local
1. Clonar el repo:
   git clone https://github.com/gvngvdoblea/Evaluacion2_Fullstack-II.git
   git clone https://github.com/gvngvdoblea/Evaluacion2_Fullstack-II.git && cd Evaluacion2_Fullstack-II && npm install && npm run dev
2. Entrar a la carpeta e instalar paquetes:
   npm install
3. Iniciar el servidor:
   npm run dev
   

---

### Funcionalidades
* Menú de productos con detalle individual (`/producto/:id`).
* Carrito de compras funcional y pantalla de checkout.
* Login y Registro con validaciones.
* Panel de administración con métricas y tabla para agregar o borrar productos del menú.
